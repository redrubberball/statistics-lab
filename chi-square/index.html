🚲 Guided Practice: Conditional Probability & Independence

Use the Orange Blossom College Bike Share dataset to review probability and explore whether two categorical variables appear related.

Nothing needs to be submitted. Try the work first, then use the hints and answer toggles to check yourself.

📌 How to Use This Guided Practice
  • In class, complete the Exploration your group is assigned.
  • If you are working online or on your own, use the Exploration your instructor indicates.
  • You may use technology for calculations.
  • Give fractions exactly, round decimals to 3 places, and percentages to 1 decimal place.
  • Open the Excel or StatCrunch tab when you want to see how the tables and graphs are created from the raw dataset.

Remember: each row of the Bike Share dataset represents one completed trip, so describe results in terms of sampled trips rather than unique participants.

⭐ The Big Connection
Raw data → two-way table → probability & conditional probability → conditional distributions → 100% stacked graph → independence / association.
Later, this same type of categorical relationship can lead to a Chi-Square Test of Independence in your project.

The completed two-way tables are provided here so you can focus first on the probability ideas.

Part 3 — Check for Independence

Overall probability — our baseline:

P(Electric) = 45/96 = 0.469 = 46.9%

Compare each conditional probability below with 46.9%.

Group Conditional Probability Percentage Compared with 46.9%
Faculty/Staff P(Electric | Faculty/Staff) Lower / About the Same / Higher
Student P(Electric | Student) Lower / About the Same / Higher
Visitor P(Electric | Visitor) Lower / About the Same / Higher
Tip: Independence is about whether knowing the group appears to change the probability. Compare each conditional probability to the same overall baseline.
✅ Check the Conditional Probabilities

P(Electric | Faculty/Staff) = 4/15 = 0.267 = 26.7% — lower than 46.9%.

P(Electric | Student) = 29/59 = 0.492 = 49.2% — about the same as 46.9%.

P(Electric | Visitor) = 12/22 = 0.545 = 54.5% — higher than 46.9%.

Because the conditional probabilities are not all about the same as the overall probability, Bike Type and Campus Affiliation appear associated / not independent in this sample.

Based on this sample, the variables appear: approximately independent / associated.

✅ Check the Interpretation

Overall, 46.9% of the sampled trips used an Electric bike. Among Faculty/Staff trips, 26.7% used an Electric bike, compared with 49.2% of Student trips and 54.5% of Visitor trips. The highest conditional Electric percentage occurred for Visitors at 54.5%, while the lowest occurred for Faculty/Staff at 26.7%. Based on this sample, Bike Type and Campus Affiliation appear associated / not independent.

Excel — Create the Tables & Graphs

Use this tab when you want to see how the Guided Practice tables and graphs can be created from the raw Bike Share dataset.

Files: BikeShareDataset.xlsx   |   [ADD WORKED EXCEL EXAMPLE LINK]

1. Create the Count PivotTable
  1. Click anywhere inside the dataset.
  2. Go to Insert → PivotTable.
  3. Choose where you want the PivotTable placed.
  4. Drag the grouping variable to Rows.
  5. Drag the other categorical variable to Columns.
  6. Drag that same variable to Values.
  7. Make sure Values displays Count of..., not Sum.

Example A: Campus_Affiliation → Rows; Bike_Type → Columns; Bike_Type → Values.

2. Create the Row-Percentage Table
  1. Copy the count PivotTable and paste a second copy nearby.
  2. Right-click a value in the copied PivotTable.
  3. Choose Show Values As → % of Row Total.

Check: each row should total 100%.

3. Create the Graphs

Count graph: click inside the count PivotTable → Insert → PivotChart → Stacked Bar.

Conditional-distribution graph: click inside the percentage PivotTable → Insert → PivotChart → 100% Stacked Bar.

Add all labels quickly: click the chart → green + button → check Data Labels.

Excel may display horizontal bar categories from bottom to top. That is okay—the graph still represents the same conditional distributions.

StatCrunch — Create the Tables & Graphs

Use this tab if you are working in StatCrunch instead of Excel.

Dataset: [ADD BIKE SHARE DATASET / STATCRUNCH LINK HERE]

1. Create the Contingency Table
  1. Open the Bike Share dataset in StatCrunch.
  2. Go to Stat → Tables → Contingency → With data.
  3. Choose the grouping variable for Rows.
  4. Choose the other categorical variable for Columns.
  5. Select Counts.
  6. Select Row percent when you want the conditional distributions.
  7. Click Compute.

Tip: Row percentages answer “Within this row group, what percentage falls into each category?”

2. Create the Graph

From the contingency-table output, use the graph options to create a bar chart that compares the row percentages / conditional distributions.

The goal is the same as the Excel 100% stacked bar graph: compare the distribution within each group rather than just the raw counts.
